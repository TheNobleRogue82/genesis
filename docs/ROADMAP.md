# Roadmap and Quality Gates

## Phase 0 — Genesis Shader Lab (FIRST)
**Goal:** prove the core beauty. Use a fixed phrase and a single deterministic galaxy.
- [ ] Project scaffold and local development workflow
- [ ] Typography sampling and particle identity/provenance
- [ ] Beautiful still-frame composition
- [ ] Flowing letter-to-filament-to-stardust transformation
- [ ] Spatial galaxy generation from the same particles
- [ ] Smooth 3D orbit/zoom/fly interaction
- [ ] Proximity-based letter recognition
- [ ] Debug presets, seed replay, screenshot/video capture
- [ ] Basic responsive and reduced-motion profiles

**Gate:** Visual review with real screenshots and a motion clip; no jarring swap, no placeholder-looking glow, convincing depth and reliable controls. Optimize before expanding scope.

## Phase 1 — Voice-to-Genesis
- [ ] Explicit microphone interaction and ~2–3s cap
- [ ] Transcription pipeline, truthful transcript/error states
- [ ] Typography formed from actual transcription
- [ ] AI-directed, schema-constrained world specification
- [ ] Immediate fallback animation during asynchronous inference
- [ ] One creation per universe, reset to speak anew

**Gate:** Speech-origin relationship is demonstrable, repeatable, and visually consistent; recording/privacy behavior verified.

## Phase 2 — Meaningful Exploration
- [ ] Multiple stellar regions, galaxies, nebulae and black hole archetypes
- [ ] Macro/micro navigation and procedural level of detail
- [ ] Word/landmark provenance and rediscovery
- [ ] Distinct seeded universes with coherent art direction
- [ ] Mobile performance and accessibility audit

**Gate:** Exploration remains worthwhile beyond the initial animation, without a prescribed endpoint.

## Phase 3 — Portfolio Release
- [ ] Cloudflare deployment integration
- [ ] Optional Intelligence Layer explaining model vs simulation vs shaders
- [ ] Privacy language, rate limits, error paths and analytics respecting consent
- [ ] Case study with real captures and documented technical decisions
- [ ] Optional save/share only if product and privacy tradeoffs support it

**Gate:** Stable publicly accessible release and an honest, visually documented case study.

## Not committed
Multiplayer, shared persistent cosmos, generative audio, mobile AR, user accounts, real astronomical catalogs and physics research-grade fidelity. Revisit only after core artistry succeeds.
